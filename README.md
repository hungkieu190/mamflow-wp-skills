## 🌟 CÂU PROMPT DUY NHẤT ĐỂ MANG ĐI BẤT KỲ ĐÂU (1-Prompt Anywhere)

Khi bạn sang **bất kỳ máy tính nào mới**, mở một dự án WordPress bất kỳ trong **Antigravity IDE**, **Cursor** hoặc **Claude Code**, bạn chỉ cần copy đúng **1 câu prompt** sau đây và gửi cho AI:

```markdown
Hãy cài đặt bộ kỹ năng phát triển WordPress chuẩn (WordPress Master Squad) từ repository:
https://github.com/hungkieu190/mamflow-wp-skills.git
vào thư mục `.agents/skills` của dự án này, đồng thời đọc kỹ hai file `WORDPRESS_CODING_STANDARDS.md` và `WP_WORKFLOW_GUIDE.md` để áp dụng bắt buộc cho toàn bộ mã nguồn WordPress trong dự án.
```

*(AI trên máy mới sẽ tự động clone repo, cài đặt toàn bộ 8 skills vào dự án và lập tức áp dụng quy chuẩn code WordPress chuẩn chỉ 100%).*

## ⚡ HOẶC CÀI ĐẶT BẰNG 1 DÒNG LỆNH TERMINAL

Nếu bạn đang mở terminal trong thư mục dự án WordPress của mình, chỉ cần chạy đúng 1 dòng lệnh:

```bash
curl -fsSL https://raw.githubusercontent.com/hungkieu190/mamflow-wp-skills/main/install.sh | bash
```

*Muốn cài đặt Global (dùng chung cho mọi dự án trên máy):*
```bash
curl -fsSL https://raw.githubusercontent.com/hungkieu190/mamflow-wp-skills/main/install.sh | bash -s -- --global
```
